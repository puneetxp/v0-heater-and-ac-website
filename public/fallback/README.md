# Fallback Product Images

This directory contains fallback images for product categories when database images are unavailable.

## Image Files

- `cooling-unit.jpg` - Generic cooling/AC unit fallback
- `window-ac.jpg` - Window AC fallback image
- `split-ac.jpg` - Split AC fallback image
- `heating-unit.jpg` - Generic heating unit fallback
- `oil-heater.jpg` - Oil heater fallback image
- `portable-unit.jpg` - Portable cooling unit fallback
- `product-default.jpg` - Default product image fallback

These images ensure a seamless user experience when product images from the database are unavailable or fail to load.
